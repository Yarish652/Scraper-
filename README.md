# SHEIN Scraper Repository

A browser-assisted SHEIN product scraper that captures SHEIN's internal product API payloads from a running Chrome session and converts them into validated JSON output.

## What this repository contains

- `shein_scraper/main.py` - single-product scraper entrypoint that attaches to an existing Chrome remote debugging session.
- `multi_product_test.py` - queue-driven multi-product experiment runner with URL deduplication, collection page expansion, recommendation discovery, and reports.
- `shein_scraper/scraper/fetcher.py` - Playwright-based CDP fetcher that captures the internal SHEIN product detail API payload.
- `shein_scraper/scraper/extractor.py` - transforms the captured JSON payload into a validated `Product` model.
- `shein_scraper/storage/json_writer.py` - writes product data to JSON files under `outputs/`.
- `shein_scraper/models/product.py` - Pydantic model for validated product data.
- `shein_scraper/config/settings.py` - centralized configuration for scraper settings.
- `shein_scraper/config/constants.py` - fixed constants and API fragment selectors.

## Quick start

1. Create and activate a Python virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

2. Install dependencies:

```powershell
pip install -r shein_scraper/requirements.txt
```

3. Start Chrome with remote debugging enabled:

```powershell
& 'C:\Program Files\Google\Chrome\Application\chrome.exe' --remote-debugging-port=9222 --user-data-dir='C:\ChromeDebug'
```

4. Run a single-product extraction:

```powershell
python shein_scraper/main.py <product_url>
```

5. Run the multi-product experiment runner:

```powershell
python multi_product_test.py --max-products 20
```

## Current workflow

- `multi_product_test.py` loads seed URLs from `urls.txt`.
- Each URL is normalized and classified as a product or collection URL.
- Product pages are opened in a running Chrome session over CDP.
- The scraper listens for SHEIN's internal `get_goods_detail_realtime_data` API response.
- The captured payload is converted to a validated `Product` model.
- Extracted products are saved as JSON files in `outputs/`.
- The runner discovers additional product URLs from collection and recommendation pages.

## Runtime outputs

- `SampleOutputs/` - extracted product JSON files, including a sampled confirmation file such as `SampleOutputs/product_0001_64112449.json`.
- `debug/` - raw API captures and anti-bot artifacts when they occur.
- `reports/` - run reports generated by `multi_product_test.py`.
- `processed_urls.txt` - persisted successful product URLs.
- `unsupported_urls.txt` - logged unsupported or malformed URLs.

## Notes

- The implementation requires Chrome to already be running with `--remote-debugging-port=9222`.
- The runtime assumes a SHEIN page is available in the attached Chrome session.
- This file describes the current scraper implementation; scaling and limitations are documented in `shein_scraper/SCALING_AND_LIMITATIONS.md`.
